SurgeSpace Licence Tool

Runs only on this computer. Nothing is sent anywhere. No signing key loaded

1 · Signing key

Activation codes are signed with your private key. Create it once, keep the file safe (for example on an encrypted USB stick and in your password manager), and never send it to anyone. SurgeSpace only contains the public key, which can check codes but not make them.

4 · Register of issued licences

The register is kept in this browser on this computer: export it regularly as a backup. "Cancel" marks a licence as cancelled; then make a new status file and upload it to lic.engspace.app/surgespace/status.txt. SurgeSpace checks that file every few days and stops a cancelled licence.
